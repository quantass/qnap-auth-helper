Custom Protocol Setup
Windows 11  ·  Firefox desktop

Directly link your files & folders in Firefox.

Normally, clicking a link to a local or network path does nothing because of browser security blocks. This guide wires up a custom protocol (like openfolder://) to safely bypass that block, handing the link directly to Windows Explorer. This opens standard folders, but it also automatically launches safe files (like .mp4 or .pdf) in their default Windows apps!

3
Test

Try it out

Paste this into the address bar (or click it if it's a hyperlink on a web page):

openfolder:\\192.168.1.2\Downloads

Firefox will show a one-time "Launch Application" prompt. Check Always allow or Remember my choice and confirm. File Explorer should immediately pop open to that folder!

Restart Not Required: Windows registers protocols instantly. You usually do not need to restart Firefox, but if the browser acts stubborn on the first try, a quick browser restart will fix it.

4
Optional (about:config)

Force Firefox to allow it

Most users can completely skip this step. The standard popup in Step 3 is enough. But if Firefox refuses to pass the link and says "unknown protocol", you can force it:

  1. Type about:config into your Firefox address bar and accept the risk warning.
  2. Paste network.protocol-handler.expose.openfolder into the search bar.
  3. If it does not exist, look below the search bar: select Boolean and click the + (Add) button.
  4. Set the value to false.

Troubleshooting

Nothing happens when I click the link

Check the openfolder.reg file you ran in Step 2. The script path inside the registry file MUST match the exact folder where you saved the VBS script in Step 1 (currently set to C:\Scripts). Don't forget the double slashes \\ in the `.reg` code!

Firefox says "unknown protocol" or remains silent after Step 4

Double-check the about:config value from Step 4. Ensure you typed the name exactly (network.protocol-handler.expose.openfolder), selected Boolean, and set the value to false. You may need to completely close and restart Firefox for the new setting to take effect.

File Explorer opens to "My Documents" instead of the target

This means Windows Explorer couldn't find the exact network or folder path you clicked. Our VBScript automatically creates a log file! Go to C:\Scripts and open launch_openfolder.log to see the exact text path Windows tried to open. This usually reveals a typo in your link.
