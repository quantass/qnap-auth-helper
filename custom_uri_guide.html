Open Network & Local Paths Directly in Firefox

Normally, clicking a link to a local or network path does nothing because of browser security blocks. This guide wires up a custom protocol (like openfolder:) to safely bypass that block, handing the link directly to your operating system.

Disclaimer: Modifying your operating system's registry, desktop entries, or URL handlers carries inherent risks. While the provided scripts include strict security blocklists to protect you from malicious links, you are implementing these custom system protocols entirely at your own risk.

4
Optional (about:config)

Force Firefox to allow it

Most users can completely skip this step. The standard popup in Step 3 is enough. But if Firefox refuses to pass the link and says "unknown protocol", you can force it:

  1. Type about:config into your Firefox address bar and accept the risk warning.
  2. Paste network.protocol-handler.expose.openfolder into the search bar.
  3. If it does not exist, look below the search bar: select Boolean and click the + (Add) button.
  4. Set the value to false.

Troubleshooting

Nothing happens when I click the link

Check the openfolder.reg file you ran in Step 2. The script path inside the registry file MUST match the exact folder where you saved the VBS script in Step 1 (currently set to C:\Scripts). Don't forget the double slashes \\ in the `.reg` code! Ensure you actually ran chmod +x on your bash script, and that the path inside the Exec= line of your .desktop file perfectly matches where you saved the script. Ensure you double-clicked the AppleScript Application at least once. macOS will not register the URL scheme inside the Info.plist file until LaunchServices sees the app run for the first time.

Firefox says "unknown protocol" or remains silent after Step 4

Double-check the about:config value from Step 4. Ensure you typed the name exactly (network.protocol-handler.expose.openfolder), selected Boolean, and set the value to false. You may need to completely close and restart Firefox for the new setting to take effect.

The OS opens "My Documents" or "Home" instead of the target

This means the operating system couldn't find the exact network or folder path you clicked. Our VBScript automatically creates a log file! Go to C:\Scripts and open launch_openfolder.log to see the exact text path Windows tried to open. This usually reveals a typo in your link.Check for typos in your path.
